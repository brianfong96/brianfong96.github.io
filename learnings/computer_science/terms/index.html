Using term tooltips in other tutorials

Any learning page can include the glossary script and get automatic hover/click tooltips:

<script src="../terms/glossary.js"></script>
<script>Glossary.init();</script>

<!-- Then mark terms: -->
<span class="term" data-term="p95">p95</span>
<span class="term" data-term="latency">latency</span>

Hovering or clicking a marked term shows the full definition inline.
