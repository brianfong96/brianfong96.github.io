Numesthesia

Pick numbers and listen to them. Each digit chooses a note or a drum and how long it rings, so π, e, the speed of light, or your own name becomes a track. Layer up to six, retune them, or roll the dice and hear what the constants make together.

Tracks

Each track plays its own number on its own sound, all on one clock. A track can also weave several numbers together, swapping between them to change up its melody or beat. Then roll the dice: fully random, or arranged with music theory.

Export

Save the current mix as audio, as MIDI for a music app, or as a CSV of every note. Audio renders faster than real time, with the loop setting, mutes, and solos as they are now.

Watch the digits

The circle draws a line from each digit to the next, one colour per track. The bars count how often each digit has played; in a normal number like π (we think) every bar settles toward one in ten.

How a digit becomes a note

Digits climb the scale from the key note, so 0 is the root and 9 sits high in the second octave. A step is an eighth note, and the score draws each note as long as it is held. The table follows the selected track: Track 1.

Text → ASCII. Each character becomes its character code, written out and joined: “Hi” is 72 and 105, so it plays 7-2-1-0-5. Characters beyond ASCII use their Unicode code point.

Mixing inside a track. Add more numbers to a track and pick how it switches: every 4 to 32 digits, digit by digit, random stretches, or letting each digit choose which number plays next. In the score, each mixed-in number draws with its own corner shape.

Importing a file. A .txt file of digits plays as written on the selected track. Spaces, line breaks, and decimal points are skipped; any other character is ignored and counted.

Where the digits come from. Constants are computed to 1,200 digits with mpmath. Since the 2019 SI redefinition, c, h, e, k, and NA are exact, and so are R, F, ħ, σ, and the others built from them. G and the particle values are measured (CODATA 2022) and end where the measurement does. Short numbers loop.
