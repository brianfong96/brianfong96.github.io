Number Music

Pick a number and listen to it. Each digit chooses a note on a scale and a hit on the drums, so π, e, the speed of light, or your own name becomes a melody you can retune, slow down, and watch unfold.

The circle draws a line from each digit to the next. The bars count how often each digit has played; in a normal number like π (we think) every bar settles toward one in ten.

How a digit becomes a note

Digits climb the scale you pick, starting from the key note, so 0 is the root and 9 sits near the top of the second octave. The drum column applies when the digit picks the drum.

Text → ASCII. Each character becomes its character code, written out and joined: “Hi” is 72 and 105, so it plays 7-2-1-0-5. Characters beyond ASCII use their Unicode code point.

Importing a file. A .txt file of digits plays as written. Spaces, line breaks, and a decimal point are skipped; any other character is ignored and counted.

The physical constants. Since the 2019 SI redefinition, c, h, e, k, and NA are exact by definition. G and the fine-structure constant are measured, so their digits are the CODATA 2022 values and end where the measurement does. Short numbers loop.
